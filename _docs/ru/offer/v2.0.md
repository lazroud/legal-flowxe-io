## 1. Предмет договора

1.1. Исполнитель предоставляет Пользователю доступ к Сервису FLOWXE Network — сервису ускорения и оптимизации интернет-соединения через распределённую сеть серверов в различных регионах мира.

1.2. Доступ к Сервису предоставляется через:

- **Telegram-бот [@flowxe_bot](https://t.me/flowxe_bot)** — основная точка входа для клиентов;
- **Веб-кабинет [cabinet.flowxe.io](https://cabinet.flowxe.io)** — личный кабинет с авторизацией через Telegram.

1.3. Пользователь получает подписочный URL для подключения совместимых клиентских приложений.

1.4. Объём услуг определяется выбранным тарифным планом.

2.2. Исполнитель вправе изменять стоимость тарифных планов. Изменение не затрагивает уже оплаченный период.

2.3. Все цены указаны с учётом применимых налогов, если иное не указано.

## 3. Порядок оплаты

3.1. Оплата производится авансом за выбранный период подписки.

3.2. Доступные способы оплаты отображаются в [@flowxe_bot](https://t.me/flowxe_bot) при оформлении заказа.

3.3. Обработка платежей осуществляется платёжными провайдерами третьих сторон. Исполнитель не хранит реквизиты карт.

3.4. Доступ активируется автоматически после подтверждения оплаты.

3.5. При включённом автопродлении отключить его можно в [@flowxe_bot](https://t.me/flowxe_bot) до даты списания.
